# Project Statement

## Problem Statement
People often share files quickly without considering how sensitive the information is, how trustworthy the recipient is, how controlled the sharing channel is, or whether access can later be revoked. This project addresses the decision-making gap by providing an offline Java simulator that evaluates a proposed file-sharing scenario before the user performs the actual sharing.

## Scope
The project accepts a structured description of a planned sharing event and evaluates it using deterministic security rules. It provides an explainable risk score, risk category, contributing reasons, recommendations, local history and a safer what-if comparison.

The project does not transmit, upload, download or modify user files.

## Target Users
- Students learning secure programming
- Small teams performing informal data-sharing checks
- Cybersecurity learners practicing risk reasoning
- Faculty demonstrating Java OOP and rule-based decision systems

## High-Level Features
1. Scenario creation and validation
2. Explainable 0–100 risk scoring
3. Risk-level classification
4. Security-control recommendations
5. Safer-alternative simulation
6. Local history of evaluated scenarios
7. Automated validation tests
